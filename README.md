Kriti Kumari — PM Portfolio

React portfolio documenting three live PM builds, deployed on Vercel.

What it does

Presents three shipped PM projects with full decision logs — what was built, what was scoped out, and why. Each project has a collapsible section showing architecture decisions, trade-offs, and thinking behind every major call. Built for hiring teams and PMs who want to evaluate decision quality, not just output. Navigates via project tabs with scroll animations and a Go Deeper section linking to PRDs, thinking docs, and GitHub.

Stack

React · Vite · Vercel

Built as

A PM-led build — product decisions, architecture, spec, and iteration owned end to end. AI-assisted development used throughout to ship faster without compromising on thinking depth or decision quality.
